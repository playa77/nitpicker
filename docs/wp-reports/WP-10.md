# WP-10 — LLM clients

Date: 2026-11-08. Baseline: origin/main `1681dc2` (fetched and fast-forwarded before implementation).

Added typed multipart AsrClient, StatementProcessor and AnalysisEngine. Segmentation and analysis share a single JSON repair attempt; analysis validates target sequence numbers and families and drops invalid quotes without discarding valid notes. Clients use the approved prompts and Gemini model. Synthetic-input unit tests exercise repair, terminal parse failure, invalid annotations, and exact WAV preservation.
