# WP-07 — ChatTransport and OpenRouterGateway

Date: 2026-11-08

## Delivered

Implemented the constructor-configurable OpenRouter chat and multipart audio-transcriptions gateway, request DTO serialization, bearer/attribution headers, cancellable OkHttp calls, off-main-thread execution, typed errors, bounded retries/jitter, Retry-After seconds/date parsing with 60-second cap, and configured timeouts. Redirects and hidden OkHttp retries are disabled to preserve authorization scope and explicit retry budgets.

## Verification

Eleven MockWebServer tests pass for payload/header/response shape, capped Retry-After and date/fallback behavior, server recovery/exhaustion, auth/client/redirect no-retry, malformed-success no-retry, read timeout budget, cancellation, exact WAV multipart fields for both ASR models, transcription retry byte preservation, and transcription auth/routing/malformed-response behavior. Live tests through the production gateway passed MAI transcription and Gemini segmentation/analysis. Whisper failed with HTTP 404 due to the independently confirmed provider guardrail restriction. The ordinary suite skips three opt-in live tests.

The combined offline `:app:testDebugUnitTest` and `:app:assembleDebug` run passed (45 tests passed, 3 opt-in live tests skipped); `:app:lintDebug` passed. See WP-07 for the separately run live API outcomes.
