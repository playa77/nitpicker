**Status:** Implemented; on-device M1 smoke pending operator device
**Branch:** `wp/01-repo-bootstrap`

## What was built

- Gradle wrapper (Gradle 9.6.0, checksum-pinned) and settings/root build scripts.
- Single `:app` Android module with AGP 9.5.0 built-in Kotlin, Compose, serialization, KSP, Room, DataStore, OkHttp and test dependencies.
- `gradle/libs.versions.toml` with all Doc 2 §3 dependencies pinned once; no dynamic versions.
- `AndroidManifest.xml` with the complete Doc 2 §7 permission set. Service declaration intentionally deferred to WP-16.
- Minimal `CompanionApp` Application stub and `MainActivity` Compose placeholder.
- Robolectric launch smoke test for the placeholder activity; `testOptions` configured for Android resources and the JDK 21 module export Robolectric needs.
- Existing `.gitignore` verified to cover Gradle/build output, `local.properties`, IDE state, APKs, and `keystore.properties` / keystore material.

## Version pins

Gradle 9.6.0; AGP 9.5.0; Kotlin compiler plugins 2.2.10 (AGP 9 built-in Kotlin, KGP 2.2.10); KSP 2.3.13; Compose BOM 2026.09.00; activity-compose 1.13.0; lifecycle 2.11.0; core-ktx 1.19.1; Room 2.8.5; DataStore 1.3.0; OkHttp 4.12.0; kotlinx-serialization-json 1.8.1; kotlinx-coroutines 1.10.2; JUnit 4.13.2; Robolectric 4.17; MockWebServer 4.12.0.

All pins meet or exceed the Doc 2 §3 floors. AGP 9 supplies Kotlin compilation built in; the separate `org.jetbrains.kotlin.android` plugin is therefore intentionally absent. The Compose and serialization compiler plugins are pinned to the built-in KGP version (2.2.10).

## Assumptions / notes

- `[ASSUMPTION]` `compileSdk`/`targetSdk` are 37 (Android 17, current stable at pin time), requiring AGP 9.5.0 / Gradle 9.6.0 and AGP 9 built-in Kotlin. KGP 2.2.10 satisfies the Doc 2 §3 Kotlin 2.0 floor.
- `[ASSUMPTION]` `versionName` is `0.1.0` for M1, per roadmap §2 milestone versioning.
- `[ASSUMPTION]` No launcher icon or app-specific theme resources were added; the platform `Theme.Material.Light.NoActionBar` is used so WP-01 stays within its file scope. The app installs with the system default launcher icon.
- `[ASSUMPTION]` `MainActivity` is a placeholder Compose screen only; navigation arrives in WP-17.
- Deferred minor (not fixed): no `<uses-feature android:name="android.hardware.microphone">` declaration; Doc 2 §7 specifies permissions, and runtime `RECORD_AUDIO` gating arrives with the Start flow in WP-17.
- `[CONFLICT]` None.
