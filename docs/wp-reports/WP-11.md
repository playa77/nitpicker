# WP-11 — ASR and segmentation orchestration

Date: 2026-11-08. Baseline: origin/main `1681dc2` (fetched and fast-forwarded before implementation).

Added independent service-scoped ASR and segmentation workers, driven by Room invalidations and network state. Claims preserve sequence order, offline work parks before dispatch, and typed transient errors requeue with a bounded durable attempt count. Successful ASR resets the shared attempt counter before segmentation; segmentation claims and retries increment it persistently. Terminal failures retain eligible WAV bytes before nulling the database blob and produce export gaps.

Authentication errors hold work until SettingsStore's ciphertext fingerprint changes. The status panel exposes the typed error; replacing the key wakes workers without restarting the session. Logs contain dispatch identifiers, durations and error types, never request content or credentials.
