## Assumptions and conflicts

[ASSUMPTION] Newest retained sessions are ordered by monotonic database session ID, rather than directory modification time (which changes during late queue backfill). Logs use elapsed time since the first log call for that session in this SessionLog instance; the later service must emit its session-start entry immediately. No pipeline timing/worker behavior is implemented here.
