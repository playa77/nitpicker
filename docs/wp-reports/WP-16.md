# WP-16 — Session foreground service

Date: 2026-11-08. Baseline: origin/main `1681dc2` (fetched and fast-forwarded before implementation).

Added START/STOP/RESUME/FORCE_FINALIZE intents, a silenced microphone foreground service, wake/Wi-Fi locks, capture→WAV→repository wiring, retention pruning and session reconstruction. STOP persists STOPPING, joins capture, waits for durable work and drain, finalizes provisional statements, exports, records the URI and completes the session. Force-finalize cancels workers before marking pending work failed and preserving eligible debug audio. Export errors keep DB state and offer an explicit retry; microphone failures surface FAILED with partial export.

Recovery uses the last persisted sequence and wall-clock session offset; the exporter derives recording gaps from chunk offsets. Locks/resources are released on completion, destruction and capture startup failures. The manifest declares the service plus the Wi-Fi access permissions its lock needs.

[ASSUMPTION] Added RETRY_EXPORT for the specified export-error retry action. Force-finalize is offered during STOPPING immediately (the UI table permits this), so the operator can also use it after the specified 120-second stall; there is no automatic timeout or partial export.

Build verified. Real foreground execution, lock behavior, notification silence and microphone loss remain device checks.
